# Привет! 👋 Меня зовут Елена Родина

## QA Engineer / Тестировщик ПО

Тестировщик с опытом тестирования EdTech-проектов и веб-приложений.

Проверяю требования и пользовательские сценарии, анализирую логику продукта, выявляю несоответствия между ожидаемым и фактическим поведением системы. Составляю тест-кейсы, чек-листы и баг-репорты, провожу функциональное, регрессионное, интеграционное, API- и нефункциональное тестирование.

## 🧪 Что я умею

- Анализировать и уточнять требования.
- Декомпозировать функциональность на отдельные сценарии.
- Применять техники тест-дизайна.
- Разрабатывать тест-кейсы, чек-листы и тест-планы.
- Проводить smoke, функциональное, регрессионное и интеграционное тестирование.
- Тестировать позитивные и негативные сценарии.
- Проверять REST API и HTTP-запросы.
- Анализировать статус-коды, структуру и содержимое ответов.
- Проверять валидацию входных данных и обработку ошибок.
- Работать с тестовыми данными и тест-ранами.
- Оформлять понятные и воспроизводимые баг-репорты.
- Анализировать результаты тестирования и готовить отчёты.
- Проводить UX/UI, адаптивное и accessibility-тестирование.
